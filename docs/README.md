# Documentation

The documentation is also published at https://haze-lang.pages.dev/docs/. Start with
[Installation](Installation.md) and [Your first model](Getting-Started.md), then
[Reading results](Reading-Results.md). The [language reference](Language-Reference.md) describes
every construct and message, [Command line and JSON](Command-Line.md) covers the `haze` command,
and [Design and semantics](Design.md) explains how Haze is built and what its results mean.

If you're new to Haze, start with the tutorial in
[`examples/Tutorial`](../examples/Tutorial) instead. To see how a Haze model can be used to test
real code, look at [`examples/Conformance`](../examples/Conformance). Individual definitions in
the implementation are documented in the docstrings of the Lean files in [`Haze`](../Haze).
