# Documentation

This directory contains the documentation for Haze.

- [`Language-Reference.md`](Language-Reference.md) describes every construct of the
  language, the commands and the messages that they produce.
- [`Design.md`](Design.md) describes how Haze is implemented, how it relates to Lean's
  implementation and the precise meaning of its results.

To learn the language, start with the tutorial in
[`examples/Tutorial`](../examples/Tutorial). The sample in
[`examples/Conformance`](../examples/Conformance) shows how to check an implementation against a
Haze model. The documentation of individual definitions in
the implementation is in the docstrings of the Lean source files in [`Haze`](../Haze).
